**Делает Logic Arrows блейзинг фаст. ⚡** \
Мод для оптимизации Logic Arrows: ускоренный движок симуляции, расширенные инструменты отладки и удобные функции для проектирования логических схем.

**Поддержка:** браузеры на базе Chromium, Firefox, Tampermonkey и Via Browser. \
**Настройки мода доступны в меню настроек внутри игры!**

## Возможности

- **Тёмная тема**
- **Оптимизация кольцевой памяти**
- **Дополнительные режимы скорости**
- **Стабильный TPS независимо от FPS**
- **Счётчик текущего тика рядом с FPS**
- **Улучшенная система сохранений**
- **Импорт сохранений из Steam** \[Вставка сохранений напрямую из Steam-версии\]
- **Режимы отладки** \[Подсветка неиспользуемых стрелок\]
- **Включение / выключение стрелок** \[P / Shift+P\]
- **Автотрассировка пути** \[ПКМ\]
- **Подсветка и фиксация цепи** \[Alt / Alt+ЛКМ\]
- **Перемещение выделенных стрелок** \[Ctrl+ЛКМ\]
- **Выделить все стрелки** \[Ctrl+A\]
- **Откат тиков** \[Shift+Enter\]
- **Брейкпоинты** \[Автопауза при подаче сигнала на два встречных блокера\]
- **Скриншоты и запись видео** \[L / Shift+L\]
- **Относительный счётчик тиков** \[Переключение кликом по счетчику FPS\]

## Установка

Все актуальные сборки доступны на странице [GitHub Releases](https://github.com/MerinPrime/GraphDLC/releases).

---

### ПК (Chrome / Edge / Brave / Opera)

1. **Скачайте архив** со страницы релизов:
   - `newchrome.zip` — **Рекомендуется** (Chrome 109+, Edge, Opera, Brave).
   - `oldchrome.zip` — для устаревших версий Chromium (без поддержки Manifest V3).
2. **Распакуйте архив** в постоянную папку _(не удаляйте её после установки)_.
3. Откройте страницу расширений: `chrome://extensions` (или `edge://extensions`).
4. Включите **Режим разработчика** (в правом верхнем углу).
5. Нажмите **Загрузить распакованное расширение** и выберите папку с распакованными файлами.

> **Как обновить:** Замените файлы в папке на новые и нажмите иконку обновления на странице `chrome://extensions`. Если что-то работает некорректно — удалите старую версию и добавьте её заново.

---

### Телефон (Via Browser)

1. Скачайте `viamobile.zip` со страницы релизов и распакуйте его.
2. Откройте Via Browser и перейдите в **Настройки** ➔ **Скрипты**.
3. Нажмите **`+`** ➔ **Импорт из файла**.
4. Выберите распакованный `.js` файл.

---

### Tampermonkey / Violentmonkey

1. Скачайте `tampermonkey.zip` со страницы релизов и распакуйте его.
2. Откройте Tampermonkey и выберите **Создать новый скрипт**.
3. Вставьте содержимое файла `tampermonkey.js` в редактор и сохраните (**Ctrl+S** / **Cmd+S**).
